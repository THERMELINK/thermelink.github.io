Reusable Components?

Tijdens dit project hebben wij een spel gemaakt in Unity doormiddel van reusable components, dit zijn kleine scripts die maar 1 functie bevatten. het voordeel van reusable components is dat je ze makkelijk kan toevoegen op bijvoorbeeld zowel de tegenstander en enemy, denk hierbij aan een HealthManager

leerdoelen

We hebben tenopzichte van normale projecten meer tijd gekregen voor dit project, hierdoor konden wij meer aandacht besteden aan het maken van clean code. dit betekend dat we code schrijven volgens bepaalde regels die er voorzorgen dat code leesbaarder en makkelijk te onderhouden word.

eindresultaat

Uiteindelijk heb ik een prototype kunnen maken voor mijn (simpele) schietspel: Dzhames Bondarev! Dzhames bondarev is een geheim agent die gevaarlijke infiltratie missies uitvoert om zo de vijandelijke strijdgroepen te verzwakken in de oorlog.

Tijdens zijn missies komt Dzhames verschillende tegenstanders tegen die hun terratorium proberen vast te houden, het is aan Dzhames de taak om de tegenstanders te verslaan en veilig terug te keren naar de exfil auto om zijn missie te voltooien!

De extraction auto aan het einde van een missie, dit is het doel van Dzhames

vanuit de missie screen kan Dzhames uitkiezen waar hij word uitgezonden
